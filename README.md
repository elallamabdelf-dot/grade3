<h1>🤖 Grade 3 Robotics Lesson Plan</h1>
<p class="subtitle">SPIKE Essential • Word Blocks | 36 Weeks | 2026-2027</p>

<!-- TERM 1 -->
<div class="term-header">
<h2>TERM 1: Happy Traveler</h2>
<p>Weeks 1–10 — Mastering SPIKE Essential with Word Blocks, precision driving, and vehicle design</p>
</div>

<div class="week">
<div class="week-header">
<h3>Week 1: Welcome to Robotics!</h3>
<span class="week-tag">🚀 Launch</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students identify robot components and explain pair programming roles.</div>
<div class="section"><strong>ACTIVITY</strong> "Robot Parts Scavenger Hunt" — find and name each piece in the kit.</div>
<div class="section"><strong>BUILD</strong> Simple driving base (follow step-by-step instructions).</div>
<div class="section"><strong>CODE</strong> First program: make the hub light up rainbow colors.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Draw and label 3 parts of the SPIKE hub. Name your partner role for today.</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, hub chargers, name tags, team role cards.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 2: Meet the Word Blocks</h3>
<span class="week-tag">💻 Coding</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students read and arrange Word Blocks to create a simple sequence.</div>
<div class="section"><strong>ACTIVITY</strong> "Block Sorting" — categorize blocks into Movement, Light, Sound, and Events.</div>
<div class="section"><strong>BUILD</strong> Continue driving base; add wheels and motor connections.</div>
<div class="section"><strong>CODE</strong> Program: move forward 2 seconds, beep, light up green.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Write the 4 Word Blocks you used today in order.</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, Word Block reference sheets.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 3: Moving with Precision</h3>
<span class="week-tag">📏 Math</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students use number inputs to control distance, speed, and time.</div>
<div class="section"><strong>ACTIVITY</strong> "Ruler Challenge" — program robot to stop exactly at 30cm, 50cm, 100cm marks.</div>
<div class="section"><strong>BUILD</strong> Stabilize driving base; test on smooth floor vs. carpet.</div>
<div class="section"><strong>CODE</strong> Experiment with speed (%) and time (seconds) to hit targets.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> If speed = 50% and time = 3 seconds, predict where your robot stops.</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, measuring tape, stopwatches.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 4: Turning & Angles</h3>
<span class="week-tag">🔄 Geometry</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students program precise turns and navigate a simple L-shaped path.</div>
<div class="section"><strong>ACTIVITY</strong> "Square Challenge" — drive in a perfect square using 4 turns.</div>
<div class="section"><strong>BUILD</strong> Adjust wheel alignment for straight driving.</div>
<div class="section"><strong>CODE</strong> Use "turn" block with degree inputs; test and calibrate.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> How many degrees does a robot turn to make a triangle? A hexagon?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, angle reference cards, large paper for tracing paths.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 5: Loops & Repetition</h3>
<span class="week-tag">🔁 Logic</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students replace repeated blocks with a loop block.</div>
<div class="section"><strong>ACTIVITY</strong> "Loop Detective" — find repeated patterns in code and simplify them.</div>
<div class="section"><strong>BUILD</strong> Add decorative elements to vehicle (spoiler, lights).</div>
<div class="section"><strong>CODE</strong> Drive in a square using ONE loop (repeat 4 times).</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Rewrite this code using a loop: [move, turn, move, turn, move, turn].</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, loop challenge cards.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 6: Sounds & Lights</h3>
<span class="week-tag">🎨 Expression</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students program multi-sensory outputs to communicate robot "mood."</div>
<div class="section"><strong>ACTIVITY</strong> "Robot Emotions" — program happy, sad, angry, and surprised robot reactions.</div>
<div class="section"><strong>BUILD</strong> Design a robot face or character using bricks on the hub.</div>
<div class="section"><strong>CODE</strong> Combine light matrix images, sounds, and motor movements.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Design a light pattern for "caution." Sketch it.</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, emotion cards, light pattern templates.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 7: Vehicle Design Challenge</h3>
<span class="week-tag">🚗 Engineering</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students iterate on a design based on testing feedback.</div>
<div class="section"><strong>ACTIVITY</strong> "Speed vs. Stability" — test different wheel sizes and gear ratios.</div>
<div class="section"><strong>BUILD</strong> Modify base vehicle for speed OR stability (student choice).</div>
<div class="section"><strong>CODE</strong> Time trial program: measure how fast vehicle crosses 1 meter.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> What ONE change made your vehicle faster? What made it slower?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, various wheel sizes, gear sets, stopwatches.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 8: Project Planning</h3>
<span class="week-tag">📋 Plan</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students create a design brief with criteria and constraints.</div>
<div class="section"><strong>ACTIVITY</strong> "Design Brief Workshop" — write problem statement, sketch 3 ideas, choose one.</div>
<div class="section"><strong>BUILD</strong> Begin prototype build based on chosen sketch.</div>
<div class="section"><strong>CODE</strong> Draft pseudocode (plain English plan) for the program.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Complete your Design Brief sheet: What problem are you solving? Who is it for?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, design brief templates, sketch paper.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 9: Build & Code Sprint</h3>
<span class="week-tag">🔨 Build</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students manage time and resources to meet a deadline.</div>
<div class="section"><strong>ACTIVITY</strong> "Sprint Schedule" — 20 min build, 20 min code, 10 min test (×3 rounds).</div>
<div class="section"><strong>BUILD</strong> Complete vehicle with passenger seating and safety features.</div>
<div class="section"><strong>CODE</strong> Program: move 50cm straight, stop safely, play arrival sound.</div>
<div class="check-in"><strong>CHECK-IN:</strong> Teacher circulates with rubric. Is your vehicle sturdy? Does your code work?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, sprint timer, rubric sheets.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 10: Town Parade & Reflection</h3>
<span class="week-tag">🏆 Showcase</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students present their work and give constructive peer feedback.</div>
<div class="section"><strong>ACTIVITY</strong> "Town Parade" — vehicles navigate marked 50cm course; class votes on categories.</div>
<div class="section"><strong>BUILD</strong> Final adjustments and decoration.</div>
<div class="section"><strong>CODE</strong> Final test runs and debugging.</div>
<div class="assessment"><strong>ASSESSMENT:</strong> Peer rubric + self-reflection journal: "What was hardest? What are you proud of?"</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, parade course, peer rubrics, reflection journals.</div>
</div>

<!-- TERM 2 -->
<div class="term-header">
<h2>TERM 2: Animals & Their Environments</h2>
<p>Weeks 11–20 — Exploring sensors, conditionals, and animal adaptations through robotics</p>
</div>

<div class="week">
<div class="week-header">
<h3>Week 11: Sensor Introduction</h3>
<span class="week-tag">🔍 Explore</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students explain how sensors collect data from the environment.</div>
<div class="section"><strong>ACTIVITY</strong> "Sensor Detective" — test what colors the sensor detects; measure distances.</div>
<div class="section"><strong>BUILD</strong> Attach color sensor and distance sensor to driving base.</div>
<div class="section"><strong>CODE</strong> Program: when sensor sees red, hub turns red; when object is near, beep.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Name 2 things a color sensor can detect. Name 1 thing it CANNOT detect.</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, colored paper, sensor reference cards.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 12: Conditionals — If/Then</h3>
<span class="week-tag">🧠 Logic</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students write conditional statements that respond to sensor input.</div>
<div class="section"><strong>ACTIVITY</strong> "Traffic Light" — robot stops at red, goes at green, slows at yellow.</div>
<div class="section"><strong>BUILD</strong> Build a simple traffic light model with colored paper.</div>
<div class="section"><strong>CODE</strong> IF color = red THEN stop; IF color = green THEN move.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Write an if-then rule for a robot that should avoid walls.</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, colored paper traffic lights, conditional logic cards.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 13: Animal Adaptations Research</h3>
<span class="week-tag">🔬 Science</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students describe how animal senses are like robot sensors.</div>
<div class="section"><strong>ACTIVITY</strong> Research station rotation: bats (echolocation), snakes (heat), bees (UV light).</div>
<div class="section"><strong>BUILD</strong> Begin sketching animal robot design.</div>
<div class="section"><strong>CODE</strong> Review sensor blocks; plan which sensors match animal senses.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Which robot sensor is most like a bat's echolocation? Explain.</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, animal research cards, books/videos about animal senses.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 14: Building Animal Robots</h3>
<span class="week-tag">🦁 Build</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students build a structure with at least one motorized moving part.</div>
<div class="section"><strong>ACTIVITY</strong> "Creature Feature" — build legs, wings, fins, or tails that move.</div>
<div class="section"><strong>BUILD</strong> Animal body with motor-driven limb or appendage.</div>
<div class="section"><strong>CODE</strong> Program basic movement for the animal part.</div>
<div class="check-in"><strong>CHECK-IN:</strong> Does your animal's moving part work smoothly? Is it securely attached?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, animal build guides, motor attachment tips.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 15: Sensor Behaviors</h3>
<span class="week-tag">🎯 Program</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students combine sensors and motors to create reactive behaviors.</div>
<div class="section"><strong>ACTIVITY</strong> "Predator & Prey" — prey robot runs when predator (hand) approaches.</div>
<div class="section"><strong>BUILD</strong> Refine animal structure for sensor placement.</div>
<div class="section"><strong>CODE</strong> IF distance < 15cm THEN run away (move fast + light alarm).</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> What happens when your sensor doesn't detect anything? Is that okay?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, predator/prey scenario cards, sensor calibration guide.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 16: Habitat Dioramas</h3>
<span class="week-tag">🌿 Art</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students design a habitat that supports their animal's survival needs.</div>
<div class="section"><strong>ACTIVITY</strong> "Ecosystem in a Box" — build rainforest, desert, ocean, or arctic scene.</div>
<div class="section"><strong>BUILD</strong> Diorama base with environmental features (trees, rocks, water).</div>
<div class="section"><strong>CODE</strong> Program animal to "find food" (green color) in its habitat.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Draw your habitat. Label 3 features that help your animal survive.</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, diorama boxes, craft materials, habitat reference photos.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 17: Debugging & Testing</h3>
<span class="week-tag">🐛 Debug</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students use a systematic approach to identify and fix code errors.</div>
<div class="section"><strong>ACTIVITY</strong> "Bug Hunt" — teacher provides broken code; students find and fix 3 bugs.</div>
<div class="section"><strong>BUILD</strong> Fix any structural issues; reinforce weak connections.</div>
<div class="section"><strong>CODE</strong> Use "step through" method: test one block at a time.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> What is the FIRST thing you check when your robot doesn't work?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, bug hunt code cards, debugging checklist.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 18: Project Integration</h3>
<span class="week-tag">🔗 Combine</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students integrate multiple components into a cohesive project.</div>
<div class="section"><strong>ACTIVITY</strong> "Integration Checklist" — verify all 5 project requirements are met.</div>
<div class="section"><strong>BUILD</strong> Final assembly: animal + habitat + sensor mounts.</div>
<div class="section"><strong>CODE</strong> Complete program with at least 1 conditional and 1 loop.</div>
<div class="check-in"><strong>CHECK-IN:</strong> Rubric self-assessment. What score would you give yourself right now?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, integration checklist, self-assessment rubric.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 19: Presentation Prep</h3>
<span class="week-tag">🎤 Present</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students organize a 3-minute presentation with demonstration.</div>
<div class="section"><strong>ACTIVITY</strong> "Pitch Practice" — rehearse with partner, time each other, give feedback.</div>
<div class="section"><strong>BUILD</strong> Final touch-ups and signage for exhibit.</div>
<div class="section"><strong>CODE</strong> Final test runs; backup plan if sensor fails.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Write your opening sentence for the Zoo Tour. Practice it 3 times.</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, timer, presentation rubric, signage materials.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 20: Zoo Tour Showcase</h3>
<span class="week-tag">🏆 Finale</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students present confidently and engage visitors with their work.</div>
<div class="section"><strong>ACTIVITY</strong> "Zoo Tour" — other classes visit; students are exhibit guides.</div>
<div class="section"><strong>BUILD</strong> Exhibit setup with dioramas and information cards.</div>
<div class="section"><strong>CODE</strong> Live demonstrations for visitors.</div>
<div class="assessment"><strong>ASSESSMENT:</strong> Peer + teacher rubric. Visitor feedback cards. Self-reflection journal.</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, exhibit labels, visitor feedback cards, rubrics.</div>
</div>

<!-- TERM 3 -->
<div class="term-header">
<h2>TERM 3: Quirky Creations</h2>
<p>Weeks 21–30 — Engineering Design Process, problem-finding, and invention building</p>
</div>

<div class="week">
<div class="week-header">
<h3>Week 21: Problem-Finding</h3>
<span class="week-tag">🔍 Discover</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students conduct interviews to identify authentic problems.</div>
<div class="section"><strong>ACTIVITY</strong> "Problem Walk" — tour school with clipboards, note 5 problems.</div>
<div class="section"><strong>BUILD</strong> None — research and planning week.</div>
<div class="section"><strong>CODE</strong> None — research and planning week.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> List 3 problems you observed. Circle the one you want to solve.</div>
<div class="materials"><strong>MATERIALS:</strong> Clipboards, problem-finding sheets, walking permission.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 22: Criteria & Constraints</h3>
<span class="week-tag">📐 Design</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students define what success looks like for a solution.</div>
<div class="section"><strong>ACTIVITY</strong> "Must/Might/Won't" — sort features into required, optional, and out-of-scope.</div>
<div class="section"><strong>BUILD</strong> Begin sketching 3 possible solutions.</div>
<div class="section"><strong>CODE</strong> Plan which sensors and motors are needed.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Write 2 "must have" and 1 "must NOT have" for your invention.</div>
<div class="materials"><strong>MATERIALS:</strong> Design brief templates, sorting cards, sketch paper.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 23: Prototype Build 1</h3>
<span class="week-tag">🔨 Build</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students build a rough prototype to test core functionality.</div>
<div class="section"><strong>ACTIVITY</strong> "Rapid Prototype" — 30-minute build challenge, no perfection allowed.</div>
<div class="section"><strong>BUILD</strong> Rough structure focusing on mechanism, not looks.</div>
<div class="section"><strong>CODE</strong> Basic motor test — does the core movement work?</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> What worked in your prototype? What definitely didn't?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, prototype rubric, timer.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 24: Test & Feedback</h3>
<span class="week-tag">🧪 Test</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students collect and act on constructive feedback.</div>
<div class="section"><strong>ACTIVITY</strong> "Feedback Carousel" — rotate to 3 other teams, give 2 stars and 1 wish.</div>
<div class="section"><strong>BUILD</strong> Note feedback on sticky notes, attach to build.</div>
<div class="section"><strong>CODE</strong> Test with real users; note what confuses them.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> What was the most useful feedback you received? How will you use it?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, sticky notes, feedback forms.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 25: Iterate & Improve</h3>
<span class="week-tag">🔄 Improve</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students justify design changes using feedback data.</div>
<div class="section"><strong>ACTIVITY</strong> "Before & After" — photograph old version, build new version, compare.</div>
<div class="section"><strong>BUILD</strong> Rebuild based on top 3 feedback items.</div>
<div class="section"><strong>CODE</strong> Refine program; add error handling.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> What changed between version 1 and version 2? Why?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, cameras/tablets, change log templates.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 26: Advanced Mechanisms</h3>
<span class="week-tag">⚙️ Mechanics</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students explain how gear ratios affect speed and torque.</div>
<div class="section"><strong>ACTIVITY</strong> "Gear Lab" — build 3 gear trains: 1:1, 1:3, 3:1; test speed and strength.</div>
<div class="section"><strong>BUILD</strong> Add gear mechanism to invention if applicable.</div>
<div class="section"><strong>CODE</strong> Calibrate motor power for new gear ratios.</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Which gear ratio is best for lifting heavy things? For moving fast?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, gear sets, weights, stopwatches.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 27: Polish & Details</h3>
<span class="week-tag">✨ Polish</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students evaluate their invention against original criteria.</div>
<div class="section"><strong>ACTIVITY</strong> "Criteria Check" — score invention 1-4 on each criterion from Week 22.</div>
<div class="section"><strong>BUILD</strong> Add labels, colors, and user instructions.</div>
<div class="section"><strong>CODE</strong> Add startup sequence and user feedback (sounds/lights).</div>
<div class="exit-ticket"><strong>EXIT TICKET:</strong> Score yourself on each criterion. Where do you need one more week?</div>
<div class="materials"><strong>MATERIALS:</strong> SPIKE Essential sets, criteria rubric, labels, markers.</div>
</div>

<div class="week">
<div class="week-header">
<h3>Week 28: Documentation</h3>
<span class="week-tag">📝 Document</span>
</div>
<div class="section"><strong>LEARNING OBJECTIVE</strong> Students create clear technical documentation for their invention.</div>
<div class="section"><strong>ACTIVITY</strong> "Write the Manual" — step-by-step instructions, troubleshooting guide, parts list.</div>
<div class="section"><strong>BUILD</strong> Take photos of build from 4 angles.</div>
<div class="section"><strong>CODE</strong> Print or screenshot final program with comments.</div>
